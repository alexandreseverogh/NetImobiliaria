## Overview

This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

## Design Thinking

Before coding, understand the context and commit to a BOLD aesthetic direction by considering:
- **Purpose**: Problem-solving function and intended audience
- **Tone**: Pick an extreme aesthetic direction (brutally minimal, maximalist, retro-futuristic, organic, luxury, playful, editorial, brutalist, art deco, soft/pastel, industrial, etc.)
- **Constraints**: Technical requirements and accessibility considerations
- **Differentiation**: The memorable, distinctive element that stands out

Execute with precision: "Bold maximalism and refined minimalism both work - the key is intentionality, not intensity."

## Frontend Aesthetics Guidelines

Focus on:
- **Typography**: Distinctive, characterful fonts paired meaningfully; avoid generic choices
- **Color & Theme**: Cohesive, committed palettes using CSS variables with dominant colors and sharp accents
- **Motion**: Use animations for effects and micro-interactions. Prioritize CSS-only solutions for HTML
- **Spatial Composition**: Unexpected layouts featuring asymmetry, overlap, and grid-breaking elements
- **Backgrounds & Visual Details**: Atmospheric depth through textures, gradients, and contextual effects

Avoid generic AI aesthetics including overused typefaces, clichéd color schemes, predictable layouts, and cookie-cutter design patterns lacking context-specific character.

Implementation complexity should match the aesthetic vision — maximalist designs require elaborate code; minimalist designs demand precision and restraint.

## Usage

Invoke with `/frontend-design` followed by a description of the interface you want to build.

Examples:
- `/frontend-design dashboard for Meta Ads campaigns with dark mode`
- `/frontend-design KPI card component with premium shadow and hover lift`
- `/frontend-design onboarding wizard with step progress and smooth transitions`
