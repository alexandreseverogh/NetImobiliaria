Integrações planejadas para o Trafego Pago:
- **Google Ads**: gestão de campanhas (além do Meta Ads já existente)
- **Google Calendar**: agendamento (provavelmente visitas/reuniões com leads)
- **Slack**: alertas automáticos quando novos leads chegam

**Why:** Expandir a plataforma para além do Meta, cobrindo Google Ads e automatizando notificações de leads via Slack.
**How to apply:** Ao implementar features, considerar que o sistema será multi-plataforma (Meta + Google Ads). Slack é canal de notificação, não de gestão. Relacionado a [[project-trafegopago]].
